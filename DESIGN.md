# VibeSwamp: контракт дизайна

Предмет: витрина и блог модов и игр EGYS1N (Украина). Кто смотрит: игроки, пришедшие из мастерской Steam, Modrinth,
Thunderstore и GitHub. Задача: за полминуты понять, что тут есть, где скачать, что вышло недавно, где сказать спасибо.
Человеку должно быть спокойно и приятно: ничего не мигает, не просит и не режет глаз.

Материал мира (то, что существует без интерфейса):
- **водостойкий полевой блокнот**: бледно-зелёная бумага, записи с датой на поле слева;
- **ремонтная мастерская**: жёлто-зелёная полоса провода заземления, бирка «в ремонте»;
- **болото**: тёмная вода, ряска, лягушка, которая выглядывает из воды одними глазами.

Направление: 31.10.2026 «зелёный / Bitter / журнал изменений». Редизайн 06.11.2026 по броску
«зелёный / каталог / крупная дата»: из варианта «Каталог» взято «сначала настоящие вещи, описание подписью»,
из варианта «Демо» — крупная дата как часть композиции. Подогнано под материал: бумага блокнота остаётся фоном,
тёмная вода болота появляется полосой под скриншотами.

Что поменялось после отзыва владельца («мозолисто, нет акцентов, нет красоты, нет отклика»):
1. Главный вид теперь скриншоты модов, крупно, на тёмной воде. Раньше были превью 160×90.
2. Иерархия контрастом: Bitter 700 крупно против Overpass 400, вторичный текст темнее, меньше линий.
3. У всего, что нажимается, есть отклик при наведении и с клавиатуры.
4. Текст для чтения 18px, строка до 66 знаков, межстрочный 1,65.

## Токены

```css
:root {
  --ground:    #F4F6F0;  /* бумага полевого блокнота: бледная зелень, не кремовый */
  --surface:   #EAEEE5;  /* поле блокнота, подложка подписи */
  --hover:     #E3E9DA;  /* строка под курсором */
  --line:      #D2D7CC;
  --ink:       #1E2619;  /* 14,3 на бумаге */
  --ink-2:     #535B4F;  /* 6,5 на бумаге: подписи, даты */
  --signal:    #4E7A2B;  /* мох: кнопка, статус «вышло», крупные даты */
  --signal-text:#3F6A1E; /* мох для ссылок в тексте: 5,9 на бумаге */
  --on-signal: #FFFFFF;
  --water:     #2A4220;  /* тёмная вода болота: полоса со скриншотами */
  --on-water:  #E8EDE1;  /* 9,3 на воде */
  --on-water-2:#B4BFAA;  /* подписи на воде, 6,1 */
  --duckweed:  #B9D27A;  /* ряска: кнопка и ссылки на воде; текст --ink на ней 9,3 */
  --wire:      #D9B300;  /* жёлтая жила провода заземления: только в узоре «в работе», никогда текстом */
}
```

Чистого белого фона и чистого чёрного текста нет: так глаз устаёт меньше.

## Шрифты

- **Bitter** 600/700: название сайта, названия проектов, заголовки, крупные даты. Брусковая антиква, как надписи
  на бирках и ящиках.
- **Overpass** 400/600: весь текст и интерфейс. Цифры (даты, подписчики, версии) с `tabular-nums`.
- Кириллица у обоих есть, украинские ї, є, ґ тоже.
- Шкала: h1 44 (телефон 32), название проекта 32, h2 28, текст 17, текст поста и описаний 18, подписи 14–15.
  Крупная дата в блоге 40.
- Разрядка 0, у заголовков от 28px −0,01em. Капса нет нигде.

## Место

- Плотность 4/10 (лендинг), высота по содержимому, никаких `100vh`.
- Отступы: 4 / 8 / 16 / 24 / 48 / 80. Роли: внутри строки / между строками группы / между группами /
  поля колонки / между разделами / вокруг полосы воды.
- Ширина страницы 1180px. Текст до 66ch. Скриншоты шире текста.
- Главная, сверху вниз: короткое вступление и живое число подписчиков; полоса воды с вышедшими модами
  (разворот: скриншот 7/12 слева, текст 5/12 справа, под скриншотом лента из четырёх превью; крупно только
  проекты с `featured`, остальные вышедшие моды ниже на той же воде строками «Ещё моды»); «Ещё не вышло»
  строками; блог строками с крупной датой на поле; «Подякувати» коротко; подвал.
- Страница проекта: сверху вода с главным скриншотом и таблицей сведений; ниже описание, все скриншоты
  в две колонки с подписями, посты блога про этот проект.
- Блог: список строками, у строки крупная дата на левом поле. Пост: дата на поле слева, текст колонкой до 66ch.
- На телефоне всё идёт одной колонкой, скриншот первым.
- Однородное идёт строками с линиями, без сетки одинаковых карточек.

## Углы, глубина, движение

- Углы 4px у картинок и кнопок, у остального 0. Теней и свечений нет: тональные поверхности и линии 1px.
- Движение: только смена состояний 120–160 мс; лягушка следит зрачками за курсором. `prefers-reduced-motion`
  отключает и то и другое.

## Фирменные детали

1. **Лягушка выглядывает из воды.** В шапке маленькая, у верхнего края полосы воды большая: над линией воды
   два полукруга-глаза со зрачками. Зрачки смотрят на курсор, по щелчку лягушка моргает и говорит «ква».
2. **Статус как в мастерской**: «вышло» сплошной квадрат `--signal`, «в работе» квадрат с диагональной полосой
   провода заземления (`--signal` и `--wire`), «готовится» пустой квадрат в рамке, «заморожено» две вертикальные
   черты паузы цветом `--ink-2`. Рядом всегда слово.
   Над разделом «Ещё не вышло» один раз проходит полоса провода заземления, как лента на участке ремонта.
   Замороженные проекты идут отдельным тихим разделом ниже, с одной честной строкой, почему пауза.
3. **Дата на поле блокнота**: в блоге день крупно цифрой Bitter, под ним месяц и год.
4. **Живые цифры**: подписчики мастерской Steam берутся из Steam API при каждой сборке. Если API недоступен,
   остаются прошлые числа, и рядом пишется дата.

## Состояния

- Ссылка в тексте: `--signal-text`, подчёркивание 1px; при наведении 2px.
- Кнопка на бумаге: фон `--signal`, при наведении темнее. Кнопка на воде: фон `--duckweed`, текст `--ink`,
  при наведении светлее.
- Скриншот: курсор-лупа, при наведении рамка 2px `--duckweed` (на бумаге `--signal`) и значок лупы в углу.
  Щелчок открывает просмотр крупно: стрелки и клавиши ←/→, Esc и щелчок мимо картинки закрывают, на телефоне
  листается пальцем. Без JS ссылка просто открывает картинку.
- Строка блога нажимается целиком: фон `--hover`, заголовок подчёркнут толще.
- Строка «Ещё не вышло» при наведении слегка подсвечивается как помощь глазу, курсор обычный.
- `focus-visible`: обводка 2px `--signal` (на воде `--duckweed`) со смещением 2px.
- Недоступная площадка (проект ещё не вышел): текст `--ink-2`, без подчёркивания.

## Тексты

- Языки: английский (`/`), украинский (`/uk/`) и русский (`/ru/`). Язык выбирается по языку браузера; выбор,
  сделанный на сайте, запоминается и важнее. В шапке переключатель из трёх коротких слов «Eng, Укр, Рус»,
  текущий язык залит `--surface`. Определения страны по адресу нет: это чужой сервис и лишние данные.
- Будничные слова, без лозунгов и восклицательных знаков. Одна мысль в одной фразе.
- Посты блога только из фактов: даты выпусков, списки изменений, числа из Steam API с датой.
- Планы будущих проектов пишутся как планы, с припиской, что они могут измениться. Над разделом «Планы»
  тот же кусок провода заземления, что и у «Ещё не вышло».
- Поддержка: одна спокойная кнопка Donatello в разделе «Сказать спасибо» и ссылка в подвале. Сначала польза
  (моды, скриншоты, новости), потом спасибо. Без наград, без давления, без просьб внутри модов: так требует EULA
  RimWorld. Отчёт об ошибке с логом назван такой же помощью, как деньги.
- Приписка Ludeon в подвале на всех страницах.

## Запрещено в этом проекте

Фиолет и сине-фиолетовые градиенты, стекло, тени-свечения, сетка одинаковых карточек, лозунги, капс,
стрелки-иконки «далее», всплывающие окна, автозапуск звука и видео, счётчики «10k+».

## Второй круг, 07.11.2026

Отзыв владельца на первый круг: «безвкусица, без анимаций, однотонный и скучный», «жаба дублируется», «у жабы нет
маскотного узнаваемого вида, как в своё время у Пепе». Что поменялось и почему:

1. **Маскот: жаба-ремонтник.** Своя, не Пепе: широкая приплюснутая голова с бородавками, янтарные глаза с
   горизонтальным зрачком-щелью, правая бровь поднята («ну и что, что болото»), повязка из жёлто-зелёного провода
   заземления с узлом и хвостиками справа. Ни губ, ни человеческой усмешки, ни белых глаз с карими зрачками.
   Рисует её `scripts/make-toad.py`: файлы в `public/brand/` (`toad-head.svg`, `toad-peek.svg`, белые и тёмные
   одноцветные для водяного знака) и `src/toad-inline.svg` для сайта. Узнаётся и тогда, когда из воды видна одна
   макушка: глаза, бровь и повязка.
2. **Одна жаба.** На главной она сидит в пруду; при прокрутке плывёт вверх и садится в шапку у слова VibeSwamp.
   Шапка липкая. На других страницах жаба сразу в шапке.
3. **Болото наверху главной**: ночная вода `--water-deep`, пруд `--water` с волной по краю, камыши, кувшинки, круги
   на воде, светлячки янтарём. Число подписчиков янтарное.
4. **Цвет у каждого главного мода**: своя тёмная полоса, цвет взят из его картинок (`tint` в файле проекта):
   Seamless World сине-зелёный `#1E3236`, Ancient Restoration ржавый `#3B2215`, Trodden Trails оливковый `#2C2E1A`,
   KFSOS Lite стальной `#262B30`. Остальные вышедшие моды строками «Ещё моды» на обычной воде.
5. **Лента кадров** под болотом: настоящие скриншоты всех проектов медленно едут, при наведении останавливаются,
   подпись с названием проекта появляется на кадре, щелчок открывает просмотр.
6. **Движение по делу**: картинки чуть приближаются при наведении, крупные блоки модов мягко проявляются при
   прокрутке (не весь текст, ничего не прячется полностью), кнопки слегка приподнимаются. Всё выключается
   `prefers-reduced-motion`.
7. **Мини-игра**: над прудом летают мухи; щелчок, и жаба ловит муху языком, счёт хранится в браузере.

Новые токены:

## Пятый круг, 07.11.2026: новый Клёп

Владелец отверг нарисованную кодом жабу («недостаточно маскотно», «без уникального вида») и попросил концепты от

русые утренние волосы, глаза «триколор» (зелёный, немного жёлтого, немного синего), очки как на его фото в GitHub.

1. Маскот теперь картинки (`public/brand`), а не SVG. Глаза больше не следят за курсором; прыжок из пруда в шапку,

## Шестой круг, 08.11.2026: «Клёп собирает болото» заново

Владелец: «слишком долгая прогрессия», «скучно и однообразно, нет своих анимаций и картинок».
1. **Темп.** Цифры подобраны симуляцией: при 4 нажатиях в секунду все восемь построек открываются за 11–14 минут,
   высший ранг за 16–20; при одном нажатии в секунду на несколько минут позже. Цены растут на 15% за штуку.
2. **Сцена.** Болото на закате (`public/brand/swamp/bg.webp`), купленные постройки встают в воду, у каждой бирка
   «×N», чем их больше, тем они крупнее. Мухи летают, их больше, чем больше улов. Постройки по очереди
   «работают» и выдают свои «+N».
3. **Свои картинки.** Восемь построек одним листом от Codex (`public/brand/swamp/*.webp`, нарезка
   `G:\CodexWork\swamp-art\cut.py`).
4. **Клёп кадрами** из `public/brand/klyop/anim/`: при нажатиях смеётся (кадры «croak» или «type» возьмёт сам, когда
   они появятся у чата маскота), машет при покупке, прыгает при новом ранге, ловит языком жирную муху, пьёт чай после
   сборки, танцует под радио, засыпает через 45 с.
5. **Новое в игре.** Шкала вайба (быстрые нажатия, полная даёт ×3 к кваканью на 8 с); девять рангов с костюмами
   Клёпа, каждый +10%; у жирной мухи три исхода (куча мух, рой ×5, Клёп в ударе ×7); ещё две сборки (Workshop,

Не делать: возвращать значки-SVG вместо картинок построек; держать сборки по минуте и больше.
